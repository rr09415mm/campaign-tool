# キャンペーン非適用リスト（Webツール）

既存回線 → 変更後回線の組み合わせごとに、**適用されないキャンペーン**（おうちスマホ割／応援割（引っ越し以外）／工事無料）を確認できる社内向けツールです。

- 外部サービスに依存しない静的ファイルのみ（フォントもOS標準、インターネット接続不要）
- iPhoneでは縦型の2ステップ画面、PC・iPadでは一覧表を表示
- HTTPSで配信するとホーム画面に追加してアプリのように起動でき、一度開けばオフラインでも表示可能

## 使い方（どれか1つ）

### A. ファイルを直接開く（いちばん簡単）
`index.html` を社内の共有フォルダ・NAS・Teams/SharePoint などに置き、ブラウザで開くだけで動きます。

### B. 社内Webサーバーに置く
`campaign-tool/` フォルダの中身をそのまま社内サーバー（IIS / Apache / Nginx など）に置きます。

## iPhoneのホーム画面に追加
Safari で開く → 共有ボタン → 「ホーム画面に追加」

## 内容を変更するとき
`index.html` の次の部分を編集します。

```js
const C={ouchi:"おうちスマホ割",ouen:"応援割（引っ越し以外）",koji:"工事無料"};   // キャンペーン名
const AFTER=["SB光 1G","SB光 10G","光+ 2.5G","光+ 10G","Air","Airレンタル"];      // 変更後の回線（列）
const ROWS=[ ["未利用",[["ouen"],["ouen"],["ouen"],["ouen"],[],["ouchi"]]], ... ]; // 既存回線ごとの非適用
```

- `[]` … 非適用なし
- `"X"` … 同一サービスのため対象外
- 変更したら `sw.js` の `CACHE` の番号（`hitekiyo-v1` → `v2`）を1つ上げると、ホーム画面アプリにも確実に反映されます
